A standalone GitHub-compatible git forge in a single Node 22 process: git smart HTTP, REST v3, GraphQL v4 and MCP over one in-memory store, with no UI, no dependencies and no outside service. It serves repositories, branches, commits, contents, issues, comments, labels, pull requests and merges, and grades 948/1000 locally against the make.fun suite (all 120 conformance checks pass).

## Run it

```sh
node --experimental-strip-types main.ts
```
